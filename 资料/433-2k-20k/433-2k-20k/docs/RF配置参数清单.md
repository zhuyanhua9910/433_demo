## 4 改参数时的联动关系

| 想改的东西 | 要同时改的属性 |
|---|---|
| 载波频率 | `FREQ_CONTROL_INTE` + `FREQ_CONTROL_FRAC_2/1/0`（三字节，除以 2^19）|
| 空中速率 | `MODEM_DATA_RATE_2/1/0`，且 `MODEM_BCR_OSR_*`、`BCR_NCO_OFFSET_*`、`BCR_GAIN_*`、`RX_CHFLT_*` 滤波系数必须由 WDS 重新生成 |
| 频偏 | `MODEM_FREQ_DEV_2/1/0`，同时影响 `MODEM_IF_FREQ` 与带宽 |
| 接收带宽 | `MODEM_CHFLT_RX1/RX2_CHFLT_COE*`（34 个系数）+ `MODEM_DECIMATION_CFG*` |
| 发射功率 | `PA_PWR_LVL`（0x7F 为最大档），`PA_MODE`、`PA_TC` 一起变 |
| 包格式 | `PKT_CONFIG1`、`PKT_FIELD_1_LENGTH`、`PKT_CRC_CONFIG`、前导码与同步字 |
| 中断 | `INT_CTL_ENABLE`(0x0100) + `INT_CTL_PH_ENABLE`(0x0101) |
