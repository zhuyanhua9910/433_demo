# Direct RX 示波器调试模式说明

> 工程：`STM32F103C8T6_WF_DEMO`（Wf4463 + STM32F103C8T6）
> 目的：用示波器观察 433MHz 解调后的基带波形，完全复刻参考 demo 的 Direct RX
> 日期：2026-11-17

## 1 怎么切换

`Core/Src/main.c` 顶部：

```c
#define DIRECT_RX_SCOPE   1     /* 1 = 直收观测固件；0 = 正常收发固件 */
```

| 值 | 固件行为 | 载波 | 速率 |
|---|---|---|---|
| **1** | 直收观测，基带从模块 GPIO0 输出，MCU 不参与收发 | **433.000 MHz** | 2 kbps |
| 0 | 正常收发（TX/RX 由 CHOOSE_MODE 跳线决定） | 433.920 MHz | 10 kbps |

两套配置独立，改一个数字重新编译即可切换，互不影响。
注意两个模式频率不同，**不能互相通信**。

## 2 硬件接法

- 探针接 **模块第 11 脚（丝印 GPIO0）**，紧挨 VCC（第 12 脚）。
  - 对应芯片 QFN20 的第 9 脚。
- 地线夹模块 GND（第 1 脚）。
- 探头 10×，阈值 1.65 V，3.3 V 逻辑。

## 3 射频参数（与 demo 的 Direct RX 完全一致）

| 参数 | 值 | demo |
|---|---|---|
| 载波 | **433.000 MHz** | 433.000 ✓ |
| 数据率 | **2 kbps** → 每位 **500 µs** | 2 kbps ✓ |
| 调制 | 2FSK，频偏 ±20 kHz | ✓ |
| 调制指数 | h = 20 | ✓ |
| 接收带宽 | 76.31 kHz | ✓ |
| 前导码 | 4 字节（8 nibbles） | ✓ |
| 同步字 | 0xB42B | ✓ |
| 帧长 | 前导 4B + 同步 2B + 数据 7B + CRC 2B = 15B = 120 bit ≈ **60 ms** | ✓ |
| 晶振校准 | `GLOBAL_XO_TUNE = 0x52` | demo 是 0x66（按各自板子校准，不通用） |

## 4 关键寄存器

| 寄存器 | 值 | 作用 |
|---|---|---|
| `MODEM_MOD_TYPE` | **0x0A** | 2FSK + 直接模式使能 |
| `PKT_CONFIG1` | **0x40** | 关闭包处理，裸基带直出 |
| `MODEM_RAW_CONTROL` | **0x8F** | raw 直通 |
| `GPIO_PIN_CFG` GPIO0 | **0x14** | mode 20 = RX data 输出（原写 0x43 是 mode 3 = 恒定高电平，已修正） |
| `GPIO_PIN_CFG` GPIO2 / GPIO3 | **0x60 / 0x61** | 模块内部 TX / RX 射频开关（**不可改**） |
| `FREQ_CONTROL_INTE/FRAC` | 0x38 / 0x0DDDDD | 433.000 MHz（433.92 时是 0x0ED916） |

## 5 示波器设置与预期波形

| 项 | 建议 |
|---|---|
| 时基 | 先 10 ms/div 看全帧（约 6 格），再 500 µs/div 看单比特 |
| 触发 | 上升沿，电平 1.65 V |
| 有信号时 | 规整方波：起始是 `0xAA/0x55` 交替前导，随后是同步字和数据位 |
| 无信号时 | 随机翻转的噪声 |

## 6 发射源要求

本模式工作在 **433.000 MHz / 2 kbps / 2FSK / ±20 kHz 频偏**，
必须用信号发生器（或另一块专门改成此参数的板子）提供信号：

| 信号源 | 能否用 |
|---|---|
| 信号发生器（433.000 / 2 kbps / ±20 kHz） | ✅ |
| 本工程正常收发模式（433.920 / 10 kbps） | ❌ 频率、速率都不对 |
| DemoCode 双向包（433.920 / 10 kbps） | ❌ 同上 |
| DemoCode Direct TX（433.920 / 2 kbps） | ❌ 频率不对 |

## 7 与 demo 的唯一差异

| 项 | 本工程 | demo | 原因 |
|---|---|---|---|
| `GLOBAL_XO_TUNE` | 0x52 | 0x66 | 晶振负载电容校准值，由各自板子的晶振决定，照抄会让频点偏几 kHz |
| GPIO2/GPIO3 | 0x60 / 0x61 | 代码里覆盖成 0x54 / 0x42 | 你的模块是 E10 类带内部 RF 开关，必须由 GPIO2/3 控制；照抄会打不开接收通路 |

其余全部一致。

## 8 限制

- 本模式 `PKT_CONFIG1 = 0x40`，包处理关闭，**MCU 收不到数据包**，只用于观测。
- 参考 demo 工程 `433-2k-20k/DemoCode` **未作任何修改**，仅作参数参照。
